# 한국어 대화 요약 3종 비교분석 및 발표 권고안

## 1. 결론

발표에서는 세 자료를 각각 소개하지 말고 다음처럼 역할을 나누어 하나의 이야기로 합치는 것이 가장 좋다.

- **주 결과와 실험 근거:** `현중`의 pko-T5 분석
- **독립 재현과 7시간 제약 실험:** 우리가 진행한 V3 KoBART 결과
- **데이터 특성·편향·운영 인사이트:** `효창.ipynb`의 EDA 일부

최종 모델 결과를 하나만 전면에 내세워야 한다면 **현중의 pko-T5 결과**를 선택한다. 공식 Validation 35,004건 전체 평가, 부트스트랩 신뢰구간, 단계별 규모 확대, 입력 형식·학습률·배치·디코딩 실험, 오류 분석까지 연결되어 있어 발표 질문에 가장 잘 방어할 수 있기 때문이다.

다만 세 결과의 ROUGE는 토큰화·전처리·디코딩·학습 조건이 완전히 같지 않으므로 `27.15 대 23.19`를 모델 구조의 순수한 우열로 말하면 안 된다. V3는 독립 파이프라인에서도 같은 과제가 학습되고, 토론 대화 약점이 반복 관찰됐다는 보조 증거로 사용한다.

## 4. 핵심 결과 비교

### 4.1 현중 pko-T5

- 학습 278,292건, 공식 Validation 35,004건 전체 평가
- ROUGE-L 공백 기준 **27.15 [26.95, 27.36]**
- ROUGE-L 형태소 기준 **45.35 [45.16, 45.54]**
- Stage A 2,000건 22.63 → Stage B 20,000건 25.16 → Stage C 전체 27.33(dev)
- 토론 대화: 공백 ROUGE-L **16.02**, 일상 대화 27.21
- Claude 단독 판정 100건: 사실 오류 15건, 핵심 누락 13건, 화자 혼동 7건
- 장점: 결과뿐 아니라 왜 그 설정을 골랐는지를 수치로 설명할 수 있음
- 한계: 단일 학습 seed, 사람 평가 미실시, 후속 개선은 독립 test 재검증 없음

### 4.2 우리 V3 KoBART

- 실제 전체 경과 378.3분, 학습 345.0분
- 학습 265,000건, 21,628 update, 시간 예산으로 종료
- 공식 Validation 35,004건 전부 평가
- 가장 긴 발화 기준선: 어절 ROUGE-L 5.88
- 미세조정 KoBART: 어절 ROUGE-L **23.19**, 글자 ROUGE-L **43.01**
- 독립 내부 holdout 4,992건: 어절 ROUGE-L **23.42 [22.95, 23.94]**, 글자 ROUGE-L **43.16 [42.74, 43.61]**
- 공식 Validation과 내부 holdout의 어절 ROUGE-L 차이: +0.23
- 토론 대화: 공식 Validation 12.03, 일상 23.25; 내부 holdout도 14.67 대 23.47
- 장점: 7시간 안에 학습·전체 평가를 끝냈고, split manifest와 SHA-256 중복 검사가 남아 있음
- 한계: 최종 생성은 시간 때문에 greedy, 단일 seed, 사람 검토표 미채점

### 4.3 효창 노트북

가져갈 만한 실제 EDA 결과는 다음과 같다.

- Training 279,992건 / Validation 35,004건, ID 중복 0
- 요약/대화 글자 압축률 약 0.257
- 신규 unigram 비율: 어절 80.5%, 어간 73.6%로 재작성 비중이 큼
- 토론 대화는 Training의 0.57%
- Validation 화자 메타데이터: 여성 84.1%, 20대 78.6%, 수도권 62.5%
- 길이 그룹 배칭 예시에서 패딩 낭비 51.8% → 8.6%, 처리 토큰 약 47.3% 감소
- 토론 요약 1,608건 중 1,607건이 `~에 대해 토론한다` 형식이라는 관찰

하지만 현재 저장된 모델 출력은 `smoke_test=True`, 2,001건·60 step·최종 100건 결과다. 반복 어절 68%, 두 문장 이상 48%, 토론 탐지 재현율 0%이므로 최종 모델 성능으로 발표하면 안 된다.

또한 `stemsub`는 표준 ROUGE가 아니라 사용자 정의 어휘 겹침 지표이며 R-1/R-2/R-L 칸에 같은 값이 들어간다. `stemsub 25.83`을 다른 두 분석의 ROUGE-L과 비교하지 않는다. 제한된 추출 oracle과 사용자 정의 지표를 섞은 “oracle 초과”, 근접 대화 소수 쌍으로 계산한 “사람 상한 약 40”, 100건 smoke 결과의 “배포 가능” 판정도 발표에서 제외한다.

## 5. 세 자료를 합쳤을 때 생기는 가장 강한 메시지

### 메시지 A. 데이터가 크다고 모든 유형을 잘 배우는 것은 아니다

- 토론은 전체의 약 0.57%뿐이다.
- pko-T5: 토론 16.02 대 일상 27.21
- V3 KoBART: Validation 토론 12.03 대 일상 23.25
- 서로 다른 모델과 파이프라인에서 같은 약점이 재현됐다.

따라서 발표의 핵심 한계는 “평균 점수 뒤에 희소 유형 실패가 숨는다”로 잡는 것이 좋다. 해결 후보는 유형 표시, 토론 오버샘플링, 별도 토론 탐지기이며, 현중의 유형 표시 실험에서는 토론 dev가 12.24 → 17.32로 개선됐지만 서비스 입력에 유형 정보가 필요해 채택을 보류했다.

### 메시지 B. 점수 하나보다 평가 설계가 중요하다

- 같은 pko-T5 예측도 공백 ROUGE-L 27.15, 형태소 ROUGE-L 45.35로 크게 다르다.
- V3도 어절 23.19, 글자 43.01로 기준에 따라 값이 크게 달라진다.
- ROUGE는 사실 오류와 화자 혼동을 직접 재지 못한다.

따라서 발표 표에는 토큰화 기준, 평가 건수, 디코딩을 반드시 함께 적고, 사실성은 별도 사람 평가가 필요하다고 결론 낸다.

### 메시지 C. 연구 성능과 실제 실행 제약은 함께 봐야 한다

- 현중 결과는 가장 강한 실험 근거와 최종 점수를 제공한다.
- V3는 7시간이라는 자원 제약 때문에 개발셋에서 더 좋았던 beam 4 대신 greedy를 선택했다. beam 4는 개발 500건에서 어절 ROUGE-L이 약 1.23 높았지만 전체 평가 예상 시간이 약 53분으로 30분 예산을 넘었다.

이 차이는 “최고 점수”와 “정해진 시간 안에 완주 가능한 시스템”의 trade-off를 설명하는 좋은 발표 소재다.

## 6. 권장 발표 구성

1. **문제 정의**: 메신저 대화를 한 문장으로 요약
2. **데이터가 어려운 이유**: 효창 EDA의 압축률·높은 재작성률·토론 희소성
3. **평가 설계**: 공백/형태소 또는 어절/글자 기준을 병기하고 test를 분리
4. **모델 선택과 실험 흐름**: 현중의 토크나이저 비교, Stage 0 → A → B → C
5. **주 결과**: pko-T5 27.15 / 45.35, 95% 신뢰구간 포함
6. **독립 재현**: V3 KoBART 23.19 / 43.01, 내부 holdout 4,992건에서도 23.42 / 43.16
7. **공통 실패 지점**: 두 모델 모두 토론 대화가 일상보다 약 9~11점 낮음
8. **정성 오류**: 사실 오류·핵심 누락·화자 혼동 사례
9. **실행 제약**: 7시간, greedy 대 beam 품질·시간 trade-off
10. **결론**: 사람 검수 전제의 초안 생성기로는 가능성이 있으나 완전 자동화는 아직 부적합

## 7. 발표에서 쓰지 말아야 할 표현

- “pko-T5가 KoBART보다 정확히 3.96점 좋다.”
  - 토큰화·전처리·디코딩·학습 설정이 같지 않아 구조의 인과 효과가 아니다.
- “효창 모델은 사람 성능의 66%다.”
  - 사람 상한 표본과 사용자 정의 지표가 신뢰할 수준이 아니다.
- “자동 점검 통과율 97%이므로 사실 정확도 97%다.”
  - 규칙 통과율은 사실성이나 전체 가이드라인 준수율이 아니다.
- “독립 내부 Test는 공식 Test다.”
  - 공식 Train의 미사용 4,992건 holdout이며 동일 출처 내부 일반화만 보여준다.
- “토론 유형 표시가 최종 해결책이다.”
  - dev에서는 개선됐지만 정답 수준과 멀고, 실제 서비스 입력 규격 문제와 독립 test 미검증이 남아 있다.

## 8. 최종 선택

발표 자료의 비중을 정하면 다음이 적절하다.

- **현중 60%:** 실험 설계, 모델 선택, 최종 결과, 오류 분석
- **우리 V3 25%:** 7시간 완주, 독립 holdout, 재현성, 품질-시간 trade-off
- **효창 15%:** 추상성, 인구통계 편향, 토론 형식, 길이 그룹 배칭 아이디어

한 문장 결론은 다음과 같다.

> pko-T5를 주 모델로 제시하되, KoBART 독립 실행에서도 기준선 대비 개선과 토론 대화 실패가 재현됐음을 보이고, 효창의 EDA로 그 원인을 데이터 희소성과 분포 편향에서 설명한다.
