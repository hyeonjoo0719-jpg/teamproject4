# 환각 독립 재판정 패키지

## 목적

KoBART 고위험 후보 40건을 두 명이 독립적으로 판정하고, 판정 일치도와 합의가 필요한 사례를 자동으로 계산한다.

이 표본은 자동 위험 점수가 높은 사례를 의도적으로 선택했다. 따라서 결과를 전체 데이터의 환각률로 사용하면 안 된다. 발표에서는 **고위험 표본에서 발견한 오류 유형의 구성과 재현성**을 설명하는 용도로 사용한다.

## 리뷰어가 할 일

1. 리뷰어 A는 `리뷰어A_실행.bat`를 더블클릭한다.
2. 리뷰어 B는 `리뷰어B_실행.bat`를 더블클릭한다.
3. 원문과 모델 생성문만 읽고 판정한다. 정답 요약·자동 점수·기존 AI 판정은 표시되지 않는다.
4. 각 사례를 입력할 때마다 결과가 즉시 저장된다.
5. 중간에 끝내려면 사실성 선택 화면에서 `q`를 누른다. 같은 파일을 다시 실행하면 이어서 시작한다.
6. 완료 후 다음 파일을 전달한다.
   - A: `results/review_reviewer_A.csv`
   - B: `results/review_reviewer_B.csv`

Python이 PATH에 설치되어 있지 않으면 터미널에서 사용하는 Python 실행 파일로 다음 명령을 실행한다.

```powershell
python review_hallucination.py --reviewer reviewer_A
python review_hallucination.py --reviewer reviewer_B
```

## 판정 기준

- `S 원문 지지`: 생성문의 모든 핵심 주장이 원문에서 확인된다. 핵심 내용 누락은 별도 질문에 표시한다.
- `I 내재적 환각`: 원문에 있는 사실을 반대로 바꾸거나, 주체·인과·시간·속성을 잘못 연결한다.
- `E 외재적 환각`: 원문에 없는 새로운 내용을 사실처럼 추가한다.
- `B 둘 다`: 내재적 오류와 외재적 추가가 동시에 있다.
- `U 판단 보류`: 원문만으로 확정하기 어렵다.

요약이 짧다는 이유만으로 환각으로 판정하지 않는다. 원문 사실을 틀리게 말하지 않고 핵심만 빠뜨렸다면 `S`와 `누락=Y`를 선택한다.

## 결과 집계

두 결과 CSV를 같은 `results` 폴더에 넣고 `결과집계_실행.bat`를 실행한다.

생성되는 파일:

- `reviewer_summary.csv`: 리뷰어별 판정 수와 Wilson 95% 신뢰구간
- `agreement_by_case.csv`: 사례별 일치·불일치
- `adjudication_needed.csv`: 두 판정이 달라 합의가 필요한 사례
- `error_type_counts.csv`: 리뷰어별 오류 유형 수
- `review_summary.md`: 발표에 사용할 수 있는 요약표
- `review_summary.json`: 코드에서 재사용 가능한 집계 결과

판정자 간 일치도는 환각/비환각 이진 기준의 Cohen's κ로 계산한다. `U 판단 보류`는 이진 κ 계산에서 제외한다.

## 독립성 유지

- 판정이 끝나기 전에는 서로 결과를 공유하지 않는다.
- 원문에 없는 정보가 정답 요약에 있더라도 정답을 기준으로 판단하지 않는다.
- 판정 완료 후에만 `adjudication_needed.csv`를 함께 검토한다.
