# 대화 요약 환각 오류 분석 및 개선안

## 1. 발표용 결론

- 현재 가장 강한 근거는 `현중` pko-T5의 **고정 100건 판정**이다. 이 표본에서 사실 오류는 **15건(15.0%, Wilson 95% CI 9.3~23.3%)**이었다.
- 사실 오류 15건 중 가장 많았던 유형은 **인과·수식 대상 오연결 6건(40.0%)**이다. 전체 100건을 분모로 보면 **6.0%**다.
- 다음은 **주체 뒤바뀜 3건(20.0%)**, **추측을 단정 2건(13.3%)**, **상태·순서 오류 2건(13.3%)**, **의미 왜곡 1건(6.7%)**, **지명 왜곡 1건(6.7%)** 순이다.
- 관찰된 오류의 중심은 대화에 전혀 없는 새 이야기를 만드는 순수 외재적 환각보다, **대화 속 사실을 잘못 연결·귀속·단정하는 내재적 환각**이다.
- 다만 판정자는 Claude 1개 모델이므로 이 15%를 실제 환각률로 확정하면 안 된다. 발표에서는 **“Claude 단독 판정 표본에서 15/100을 관찰했다”**라고 표현한다.
- 현재 KoBART 39,996건에는 자동 규칙을 적용해 검토 후보를 만들었다. 이 값은 **환각률이 아니라 검토 우선순위**다.

## 2. 무엇을 환각으로 셌는가

| 구분 | 정의 | 이번 분석의 처리 |
|---|---|---|
| 사실 오류/환각 | 생성문이 원문과 모순되거나 원문이 뒷받침하지 않는 사실을 단정 | 주 분석 대상 |
| 화자 혼동 | A의 행동·의견을 B에게 귀속 | 사실 오류와 겹칠 수 있어 별도 태그도 유지 |
| 핵심 누락 | 원문 사실을 틀리게 말하지는 않지만 결론·핵심 사건을 빠뜨림 | 환각률과 분리 |
| 표현 변경 | 원문과 단어는 다르지만 의미가 동일 | 정상 요약 |
| 형식 위반 | 토론형 요구 등 출력 형식을 지키지 않음 | 환각과 분리 |

ROUGE가 낮다는 이유만으로 환각으로 세지 않았다. 실제로 pko-T5 표본에는 **ROUGE-L=0이지만 의미상 정상인 사례가 3건** 있었다.

## 4. 어떤 조건에서 많이 발생했는가

### 확정해서 말할 수 있는 것

**오류 유형 기준으로는 인과·수식 대상 오연결이 가장 많았다: 6/15, 40.0%.**

이는 대화 요약에서 모델이 여러 발화의 핵심 단어는 보존하더라도, `누가-무엇을-왜-언제` 관계를 재조합하는 과정에서 틀리는 문제가 가장 컸다는 뜻이다.

### 아직 확정할 수 없는 것

대화 길이·유형·화자 수별 **환각 발생률**은 기존 100건 판정표와 교차 집계가 남아 있지 않아 확정할 수 없다. 대신 전체 성능 대리 지표는 다음과 같다.

| 비교 | Word ROUGE-L | 차이 |
|---|---:|---:|
| 일상 대화 | 27.214 | 토론보다 +11.194 |
| 토론 대화 | 16.020 | 가장 낮음 |
| 짧은 대화 | 30.877 | 긴 대화보다 +7.606 |
| 긴 대화 | 23.271 | 낮음 |
| 2인 대화 | 27.226 | 3인 이상보다 +1.058 |
| 3인 이상 | 26.168 | 소폭 낮음 |

![취약 조건의 품질 대리 지표](./02_quality_risk_slices.png)

이 결과는 토론·긴 대화가 **검토 우선 대상**임을 보여주지만, ROUGE가 낮다는 이유만으로 환각이 더 많다고 결론 내릴 수는 없다. 실제 화자 혼동 표본도 2인 6/91, 3인 이상 1/9여서 “화자가 많을수록 반드시 더 나쁘다”는 근거는 부족하다.

## 5. KoBART 39,996건 자동 후보 탐색

대상은 공식 Validation 35,004건과 독립 내부 Test 4,992건이다. 숫자·부정·인과·불확실성·시간·극성의 변화를 규칙으로 표시했다.

### 독립 내부 Test 4,992건의 자동 신호

| 자동 신호 | 후보 수 | 후보율 | 해석 |
|---|---:|---:|---|
| 추측 표현 소실 | 1,387 | 27.78% | 질문/추측이 요약에서 빠진 경우. 정상 압축도 다수 포함 |
| 시간 표현 소실 | 946 | 18.95% | 시간·순서 표지가 사라진 후보 |
| 인과 표현 새로 추가 | 421 | 8.43% | 원문에 명시되지 않은 인과를 만들 가능성 |
| 부정 표현 새로 추가 | 401 | 8.03% | 긍정/부정 반전 가능성 |
| 새 숫자 생성 | 29 | 0.58% | 원문에 없는 숫자 생성 가능성 |
| 극성 반전 사전 탐지 | 8 | 0.16% | 밝다/어둡다, 좋다/싫다 등 반대 속성 후보 |

이 수치는 규칙의 **재현율 중심 후보율**이며 실제 환각률이 아니다. 예를 들어 추측 표현이 사라져도 핵심 사실만 올바르게 압축했다면 정상이다. 따라서 `hallucination_review_100.csv`의 원문·정답·생성문을 사람이 읽고 최종 확정해야 한다.

자동 후보를 직접 확인한 예에서는 다음이 실제 오류로 보였다.

- `c31184b3-...`: “이미 본 추천작” 대화를 “추천작이 싫어서 다 못 봤다”로 반전.
- `42393080-...`: 2층도 괜찮다는 대화를 “2층은 싫다”로 생성.
- `8d32dacb-...`: 어두운 주방을 “너무 밝다”로 반전.
- `ce0b11ae-...`: 아이의 점퍼루 거부와 나눔 계획을 언니의 행동으로 잘못 결합.
- `58e71b49-...`: 원문에 없는 “괜찮다고 한다”를 추가.

KoBART 내부 Test의 자동 위험 점수 상위 후보 40건을 원문·정답·생성문 순서로 다시 읽었다. 판정자는 Codex 단독이며 표본도 고위험 후보로 편향되어 있으므로 전체 환각률이 아니다.

## 6. 원인 분석

| 관찰된 오류 | 직접 원인 가설 | 근거 수준 |
|---|---|---|
| 인과·수식 대상 오연결 | 요약 과정에서 내용어는 남기지만 사건 관계를 압축·재조합하면서 잘못 연결 | 실제 최다 유형 6/15로 관찰됨. 내부 표현 원인은 추가 실험 필요 |
| 주체 뒤바뀜 | 여러 화자의 발화를 한 문장으로 합치며 발화자 표지를 잃음 | 100건 중 3건의 사실 오류와 별도 화자 혼동 7건 관찰 |
| 추측→단정 | 생성 손실이 사실성보다 자연스러운 단정문을 선호하고, 불확실성 표지가 요약에서 탈락 | 2건 관찰. 자동 후보는 많지만 오탐 가능성이 큼 |
| 상태·순서 오류 | `하려다/했다`, `전/후`, 계획/완료 차이를 짧은 요약에서 합침 | 2건과 대표 사례 확인 |
| 지명·숫자 왜곡 | 디코더가 원문 토큰을 복사하는 대신 유사한 토큰을 생성 | 각 1건 또는 자동 후보로 확인. 전체 빈도는 사람 판정 필요 |
| 긴 대화·토론 취약 | 입력 정보가 많거나 유형 형식이 특수해 관계 선택이 어려움 | ROUGE 하락은 확인, 환각 증가의 인과는 미확인 |

## 7. 해결 방법과 우선순위

### 1순위: 생성 후 사실성 검증과 재선택

1. greedy와 beam 후보를 4개 생성한다.
2. 각 후보에서 `주체-행동-대상-원인-시간-양태`를 추출한다.
3. 원문이 각 주장(claim)을 뒷받침하는지 NLI/LLM 판정과 규칙 검사를 함께 적용한다.
4. **원문 지지율이 가장 높은 후보**를 선택한다.
5. 모든 후보가 숫자·고유명사·부정·양태 검사를 실패하면 원문 발화를 직접 압축한 추출형 후보로 폴백한다.

현재 KoBART 디코딩 실험 500건에서는 beam4가 greedy보다 Word ROUGE-L **24.85 vs 23.62(+1.23)**였지만, 시간 제약 때문에 전체 생성은 greedy로 수행했다. 다음 실험은 ROUGE뿐 아니라 사실 오류율로 디코딩을 선택해야 한다.

### 2순위: 오류 유형 중심 파인튜닝

- 인과 반전, 주체 교환, 추측 삭제, 전후 순서 반전 문장을 **hard negative**로 만든다.
- 정답 요약과 오류 요약을 함께 주고 정답을 선호하도록 contrastive/ranking loss를 추가한다.
- 오류가 많았던 인과·대상 오연결 사례를 우선 증강한다.
- 화자 토큰을 삭제하지 말고 `P01`, `P02`를 유지한 입력과 화자별 사건 태그를 비교한다.
- `같다/아마/일까/려다가/이미/아직` 등 양태·시간 표지를 보존하는 표본을 과표집한다.

### 3순위: 구조화된 입력과 보조 과제

- 입력을 `화자 | 행동 | 대상 | 시간 | 확실성` 구조로 직렬화한 뒤 요약한다.
- 보조 과제로 화자 귀속 정확도와 사건 순서 판별을 함께 학습한다.
- 고유명사·숫자는 생성 후 원문 목록과 exact-match 검사하고, 불일치 시 재생성한다.

### 4순위: 길이·유형별 처리

- 긴 대화는 구간 요약 → 사건 통합의 2단계 계층 요약을 비교한다.
- 토론 대화는 입력에 유형 태그를 붙이고 `쟁점-입장-근거-결론` 템플릿을 사용한다.
- 유형별로 동일한 디코딩 설정을 고집하지 말고, 고정 검증셋에서 factuality를 함께 튜닝한다.

## 8. 검증 실험 설계

| 단계 | 비교 | 고정할 것 | 주요 지표 |
|---|---|---|---|
| B0 | 현재 greedy | 모델·데이터·표본 | 사람 사실 오류율, 유형별 건수, ROUGE-L |
| B1 | beam4/후보 4개 | 모델·학습 체크포인트 | 사실 오류율, 추론 시간, ROUGE-L |
| B2 | B1 + 사실성 reranker | 생성 후보 동일 | claim 지지율, 오류 유형별 감소 |
| B3 | hard-negative 파인튜닝 + B2 | 평가 표본·디코딩 | 인과/주체/양태 오류율 |
| B4 | 화자 구조화·계층 요약 | 학습량·seed·평가 표본 | 긴 대화, 토론, 화자 혼동 층화 결과 |

권장 판정 절차:

1. 개발용 고정 200건을 길이·유형·화자 수로 층화한다.
2. 두 명이 독립적으로 `정상/환각/누락/화자혼동/형식`과 세부 유형을 판정한다.
3. 의견 불일치를 합의하고 Cohen's κ를 보고한다.
4. 같은 표본과 같은 체크포인트로 한 번에 변수 하나만 바꾼다.
5. 목표는 예를 들어 사실 오류 **15/100 → 8/100 이하**, 인과·대상 오연결 **6/100 → 2/100 이하**, ROUGE-L 저하는 **0.5 이내**로 사전에 정한다.

## 9. 발표 슬라이드 구성안

1. **문제 정의**: ROUGE와 사실성은 다르다. 누락과 환각도 분리한다.
2. **결과**: 100건 중 사실 오류 15건, 가장 큰 유형은 인과·수식 대상 오연결 6건(40%).
3. **실패 사례 시각화**: 원문 근거 → 잘못된 생성 → 오류 지점을 색으로 연결한다.
4. **취약 조건**: 토론·긴 대화의 ROUGE 하락을 보여주되 환각률로 과해석하지 않는다.
5. **해결 파이프라인**: 다중 후보 생성 → 사실성 검사 → rerank → 실패 시 폴백.
6. **검증 계획**: B0~B4 단계별로 사실 오류율과 ROUGE를 함께 비교한다.

## 10. 한계

- pko-T5의 100건 오류 분류는 Claude 단독 판정이다.
- KoBART 39,996건 자동 규칙은 후보 생성용이며 실제 환각률이 아니다.
- pko-T5의 사람형 판정 결과를 KoBART의 환각률로 이전할 수 없다.
- 토론·긴 대화·화자 수별 환각률을 직접 교차 집계하지 못했다.
- NLI reranker, hard-negative 학습, 계층 요약의 개선 효과는 아직 실험하지 않았다.
- test를 반복 튜닝에 사용하면 누수가 생기므로, 해결법 선택은 새 개발 표본에서 하고 최종 평가는 별도 미사용 표본에서 한 번만 수행해야 한다.
